Project Foundation

Clinical Context & Objectives

Unscheduled patient absenteeism and unbalanced clinical queues severely degrade healthcare delivery efficiency and inflate provider overhead.

The Problem Statement

Modern healthcare facilities encounter systemic operational bottlenecks: high patient no-show rates leave physician slots empty, while unbalanced scheduling causes prolonged waiting room times in high-demand departments like Orthopedics and Neurology.

Average 15%–25% no-show frequency causes severe revenue leakage.
Physician capacity imbalances lead to clinician burnout or underutilization.
Lack of unified OOP data pipelines slows clinical decision-making.

Project Objectives

This showcase demonstrates how software design principles (OOP) merge seamlessly with data science workflows (Pandas) to transform raw appointment logs into actionable operational intelligence.

Model real-world entities cleanly using Encapsulation, Inheritance, and Abstraction.

Core Principle 01

Encapsulation

Protecting internal states with private attributes and defensive property setters.

Python 3.11 
class Appointment:
    def __init__(self, apt_id, patient, doctor, fee):
        self.apt_id = apt_id
        self._patient = patient
        self._doctor = doctor
        self.__wait_time = 0.0  # Private state
        self._fee = fee

    @property
    def wait_time(self) -> float:
        return self.__wait_time

    @wait_time.setter
    def wait_time(self, minutes: float):
        if minutes < 0:
            raise ValueError("Wait time cannot be negative.")
        self.__wait_time = float(minutes)
Core Principle 02

Inheritance & Polymorphism

Specializing clinical individuals from a common base entity with custom behaviors.

Python 3.11 
class Person:
    def __init__(self, person_id: str, name: str):
        self.person_id = person_id
        self.name = name

    def get_role_details(self) -> dict:
        return {"id": self.person_id, "name": self.name}

class Doctor(Person):
    def __init__(self, doc_id, name, specialty):
        super().__init__(doc_id, name)
        self.specialty = specialty

    # Polymorphic method override
    def get_role_details(self) -> dict:
        base = super().get_role_details()
        base.update({"role": "Doctor", "specialty": self.specialty})
        return base
Core Principle 03

Abstraction

Standardizing analytics contracts via Python ABC (Abstract Base Classes).

Python 3.11 
from abc import ABC, abstractmethod
import pandas as pd

class AbstractHospitalAnalyzer(ABC):
    @abstractmethod
    def compute_kpis(self) -> dict:
        """Calculate executive metrics."""
        pass

    @abstractmethod
    def generate_department_summary(self) -> pd.DataFrame:
        """Aggregate department utilization."""
        pass

class HospitalAnalyzer(AbstractHospitalAnalyzer):
    def compute_kpis(self) -> dict:
        return {
            "total": len(self.df),
            "no_show_rate": (self.df['status'] == 'No-Show').mean() * 100
        }
Data Processing Pipeline

Vectorized Pandas Analytics

Exploring the 5-stage transformation pipeline from raw nested OOP objects into high-throughput Pandas DataFrame operations.

Stage 01

Data Ingestion & Cleaning

Type coercion, parsing dates into datetime indices, and imputing null values.

pandas_cleaning.py 
import pandas as pd

def clean_appointment_dataset(raw_records: list) -> pd.DataFrame:
    df = pd.DataFrame(raw_records)

    # 1. Datetime parsing with temporal features
    df['appointment_date'] = pd.to_datetime(df['date'])
    df['month'] = df['appointment_date'].dt.month_name()
    df['day_of_week'] = df['appointment_date'].dt.day_name()

    # 2. Categorical optimization for memory efficiency
    df['status'] = df['status'].astype('category')
    df['department'] = df['department'].astype('category')

    # 3. Defensive sanitization: zero out wait time for no-shows
    df.loc[df['status'] != 'Completed', 'wait_time'] = 0.0
    return df

Stage 03

Multi-Metric GroupBy Aggregation

Departmental summaries computing volume, average wait time, and billings.

pandas_groupby.py 
# Compute multi-dimensional departmental operational matrix
dept_kpi_summary = df.groupby('department', observed=False).agg(
    total_appointments=('id', 'count'),
    completed_visits=('status', lambda s: (s == 'Completed').sum()),
    no_show_count=('status', lambda s: (s == 'No-Show').sum()),
    avg_wait_minutes=('wait_time', lambda w: w[w > 0].mean()),
    total_revenue=('fee', 'sum')
).reset_index()

# Add calculated completion efficiency percentage
dept_kpi_summary['completion_rate'] = (
    dept_kpi_summary['completed_visits'] / dept_kpi_summary['total_appointments']
) * 100
Stage 04

Temporal Analysis & Resampling

Resampling monthly throughput trends and discovering peak weekday risk factors.

pandas_timeseries.py 
# Time-series index conversion
ts_df = df.set_index('appointment_date')

# Monthly resampled throughput and no-show counts
monthly_stats = ts_df.resample('ME').agg({
    'id': 'count',
    'status': [
        ('completed', lambda s: (s == 'Completed').sum()),
        ('no_show', lambda s: (s == 'No-Show').sum())
    ],
    'fee': 'sum'
})

# Weekday peak analysis
weekday_noshow_matrix = df.pivot_table(
    index='day_of_week',
    columns='status',
    values='id',
    aggfunc='count',
    fill_value=0
)

Data-Driven Discoveries

Key Analytical Insights

Critical observations extracted from multi-dimensional aggregation across clinical specialties, scheduling windows, and patient adherence records.

Peak No-Show Rate
23.8%
Monday mornings and Friday afternoon appointment slots exhibit significantly elevated rates of absenteeism compared to midweek intervals (Tue–Thu avg: 11.4%).
Clinical Action Deploy automated SMS and phone call reminders 24 hours prior to Monday morning consultations.
Highest Patient Volume
42.5%
General Medicine and Pediatrics account for over 42% of total clinical traffic, creating chronic check-in queue congestion during morning hours.
Clinical Action Introduce staggered 15-minute staggered arrival windows and self-service kiosk check-in.
Wait Time Disparity
34.2 min
Orthopedics recorded the longest average patient wait time (34.2 mins) — more than double General Medicine (14.1 mins) — driven by complex diagnostic imaging reviews.
Clinical Action Pre-buffer imaging review buffers (10 mins) prior to patient arrival in specialized clinics.
Capacity Asymmetry
Δ 38%
Significant workload variation observed: senior specialists average 12 consultations/day, while junior clinic staff average 7, leading to scheduling inefficiencies.
Clinical Action Implement dynamic load-balancing in appointment dispatch algorithms.
Unrealized Revenue
$34,800/yr
Extrapolated financial analysis indicates annualized revenue losses of $34,800 per physician resulting from unbilled, non-rescheduled no-show appointment slots.
Clinical Action Institute a refundable 24-hour cancellation deposit policy and automated waitlist backfilling.

Project Conclusion

This project successfully demonstrates the synergy of Object-Oriented software engineering and modern Pandas data analytics. By modeling business entities into explicit classes (Patient, Doctor, Appointment), business rules remain tightly encapsulated, while the vectorized HospitalAnalyzer pipeline delivers lightning-fast multi-dimensional KPI discovery for hospital administrators.

Modular Architecture

Encapsulated entities make adding billing codes or insurance providers effortless without breaking ETL scripts.

Transparent identification of bottleneck departments directly informs staffing and facility decisions.
